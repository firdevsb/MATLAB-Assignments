# Numerical Methods & Computational Modeling in MATLAB

This repository contains a collection of MATLAB implementations focused on numerical methods, computational modeling, and biological data analysis. Each module explores specific numerical algorithms, performance metrics, and error analysis compared against analytical ground truths.

---

## 🛠️ Overview of Methods & Topics

| Topic | Methods & Concepts Implemented | Focus Area |
| :--- | :--- | :--- |
| **Linear Systems** | Gaussian Elimination, Jacobi Iteration, Norm Errors ($\|Ax-b\|_2$) | Matrix Solvers & Convergence |
| **Interpolation & Fitting** | Lagrange, Newton Divided Differences, Exponential Least-Squares | Noise Sensitivity vs. Trend Modeling |
| **Numerical Differentiation** | Forward, Backward, and Central Finite Differences | Bioprocess Kinetics & Growth Rates |
| **Differential Equations** | Modified Euler (Heun's), 4th-Order Runge-Kutta (RK4) | Non-linear ODE Simulation & Clearance |
